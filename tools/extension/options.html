Connect your review inbox

The extension adds sealed batches to inbox.json in your repo, exactly like the weekly robot. It needs a GitHub token that can only touch that one repo.

Make the token (2 minutes)

  1. Open github.com → new fine-grained token.
  2. Name it “Add to Northline”. Expiration: 90 days.
  3. Repository access: Only select repositories → northline-house.
  4. Permissions → Repository permissions → Contents: Read and write. Leave everything else as it is.
  5. Generate, copy it, paste it below and press Save.

The token stays in this browser only (Chrome’s extension storage). It is never put in the site or the repo. If you lose this computer, delete the token on GitHub.
