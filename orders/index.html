Connect to save

Saving writes orders.json to your northline-house repository. The token stays on this phone or computer only.

How to make the token (2 minutes, once)
  1. On GitHub: Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token.
  2. Name it “Northline orders”, expiry 1 year, Repository access: Only select repositories → northline-house.
  3. Permissions → Repository permissions → Contents: Read and write. Nothing else.
  4. Generate, copy the token and paste it below.
